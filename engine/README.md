# Kamishibai のエンジン

タグで書いた HTML の原稿をブラウザで直接開くと、その場でスライドに組む仕組みです。ビルドは要りません。
発表の後に配るときは、`make pack` で一つの HTML ファイル（配布用ファイル）にまとめます。
コマンドはすべて repository の最上位で実行します。

## 準備

```
make engine-fonts        # Boadilla の書体の CSS engine/fonts/kamishibai-fonts.css を作る（git で追跡しない。約 13 MB）
```

この CSS が無くても原稿は開けます。そのときは手元の書体（Hiragino など）で出ます。
Madrid の書体（Computer Modern Sans と IPA Pゴシック）の CSS は `engine/fonts/` に同梱されているので、作る必要はありません。

## 書き方

見本は [sample.html](sample.html) です。原稿の最初に

```html
<html lang="ja" theme="Boadilla">
<script src="engine/kamishibai.js"></script>
```

と書き（`src` は原稿から `engine/kamishibai.js` への相対パス）、その後ろに表紙 `<cover>`・ページ `<slide title="…" sec="…">`・区切りのページ `<divider>` を並べます。
表紙には `<headline>題名</headline>`・`<subtitle>副題</subtitle>`・`<author aff="所属" presenter>名前</author>`（何人でも。`presenter` は発表者）・`<meeting>会の名前</meeting>`・`<date>日付</date>` を書きます。
Madrid の下の帯に出す短い形は、`author`・`headline`・`date` の `short="…"` に書きます。
`sec` は上端の帯に出る節の名前で、`sec` のあるページから、別の名前の `sec` の前までが一つの節です。
使えるタグ・class・属性・キーの一覧は [kamishibai.js](kamishibai.js) の最初の説明にあります。主なものは次のとおりです。

- 本文：段落 `p`、箇条書き `list`/`item`、短い注意を緑の枠で囲む `note`、話の帰結を赤い下向きの矢印の下に出す `down`、段組み `columns`/`column`、図 `figure`、表 `table.tbl`
- block（Beamer の block）：`block`・`alertblock`・`exampleblock`
- 証明など：強調 `alert`、証明 `proof`、証明の方針 `plan`、後で証明する主張 `later`、番号つきの手順 `nums`
- 図の切り替え：重ねた図 `flip` と、それを切り替えるボタン `switch`。組み上がる図は `flip anim`（下の「図の切り替え」「組み上がる図」）
- ラベル：行の中の小さな枠 `span.label`（下の「ラベル」）
- 数式：文の中は `$…$`・`\(…\)`、別の行に取るときは `$$…$$`・`\[…\]`
- 段階表示：どの要素にも `step` を付けると、クリックや → で一つずつ出ます。`with="prev"` を付けると直前の段階と一緒に出ます

### 図の切り替え

`<flip id="…">` の中に SVG（または画像）を並べると、同じ場所に重ねて一枚ずつ見せます。大きさはいちばん大きな図に合わせ、`width`・`height`（px）でも決められます。
`<switch for="…">` の中のボタンが、同じ id の flip の図を順に切り替えます（1 番目のボタンで 1 枚目の図）。

```html
<flip id="fyn"><svg>…できる例…</svg><svg>…できない例…</svg></flip>
<switch for="fyn"><button>できる</button><button>できない</button></switch>
```

### 組み上がる図

`<flip id="…" anim>` の中の SVG では、`class="cd"` の群（カード）を一つずつ、`class="ov"` の群をまとめて出せます。
段階の要素に `cards="n"` を付けるとその段階で n 枚目のカードまで出て（`*` は全部）、`ov` を付けると `class="ov"` の群が出ます。`init="n"` は最初から出ているカードの数です。
一つの flip に SVG が複数あるときは、`cards="a|b"` で 1 枚目の SVG に a 枚、2 枚目に b 枚と図ごとに決めます。
数でも `*` でもない値は数えず、`make pack` が警告します。
文を出さずに図だけを進めるときは、文のない `<span step cards="n"></span>` を置きます。

### ラベル

ラベル（`<span class="label">`）は行の高さに収まる小さな枠です。段落・項目・block の先頭に置くと、続く文は枠の右にそろえて折り返します。
ラベルの後ろの空白は要りません（置いても除かれます）。文の途中に置けば行の中に出ます。

### 規則

聴衆が一度で読み取れるページにするため、次の規則を置いています。ここに挙げるのは機械で確かめる規則で、定義・定理・証明の文の書き方は [docs/math-slides.md](../docs/math-slides.md) にあります。
`make pack` は配布用ファイルを作る前にこれらの規則を検査し、反する原稿からは作りません（前に作った `.dist.html` も消します）。

- block には定義・定理などの主張を一つだけ入れ、題は主張の種類（定義・定理・補題・系・命題・予想・未解決問題など）で始めます。
  説明・注意・使い道・図・出典・段階表示は block の外に書きます。原稿を開くと、題が種類で始まらない block に赤い破線が出ます。
- 主張の種類はラベル（`span.label`）でなく block の題で示します。未解決問題の提起者は題の括弧に人名で並べ（頭文字と姓の間は `&nbsp;`）、
  文献の中の問題の番号は `cite` に文献（著者名と年）とともに書き、同じページの出典 `<p class="src">` でその文献を示します。
  例：`<block title="未解決問題（M.&nbsp;Demaine、F.&nbsp;Hurtado）" cite="[Demaine-O'Rourke 2007, Open Problem 25.6]">`。題の帯は 1 行に収めます。
- ページの番号で参照しません（「ページ 4」「次のページ」）。聴衆はページを戻れないので、定理の番号か内容の名前で言います。
  block の中の「頁 n」は `make pack` が拒みます（block の外は検査しません）。
- 図にはキャプションを付けません（`figcaption`、`p.cap`、「図：…」「左：…右：…」で始まる文）。図の読み方は話して伝え、ページの文は主張と議論だけにします。
  図に付けた呼び名など後で使う名前は、ページの項目で導入します。`figcaption` と `p.cap` は原稿を開けば表示されますが、`make pack` は拒みます。
- 図はページの文の下に置きます。図の後ろに置けるのは、別の図、出典（`p.src`）、図だけを進める文のない段階（`<span step cards="n"></span>`）だけです。
  アルゴリズムの解説など同じ図で段階を追う説明に限り、`<side><div>文</div><figure>図</figure></side>` で文を左、図を右に並べます（`side` の中では書いた順によらず図が右に来ます）。
  どのページが段階を追う説明かは機械では判定しないので、`side` を使うページは書き手が選びます。
- 図は表示する幅で描き、縮めて収めません。`style="zoom:…"` で縮めた図の最小の文字が 10px より小さくなると、`make pack` が警告します（配布用ファイルは作ります）。
  警告が出たら、図の説明を話す側へ移すか、意味の境目でページを分けます。

## 見る・直す

```
make preview SRC=talk/talk.html            # スライド用のブラウザで開く（開いていれば再読み込み）
make order SRC=talk/talk.html              # 定理・補題・定義の読む順の警告（../README.md の「読む順の検査」。GAP=・SHORT= で閾値）
make shot SRC=talk/talk.html PAGES="4 12"  # 4 ページ目と 12 ページ目を 1280×720 の PNG に撮る（shots/p4.png など）
```

`make preview` が開くブラウザは既定で Google Chrome で、`SLIDE_BROWSER="Brave Browser"` のように変えます（make の変数でも環境変数でもかまいません）。
原稿は開くたびに組まれるので、保存してブラウザを再読み込みすれば変更が出ます。
URL の `#s<n>` で開くページを指定できます（`talk.html#s5` は 5 ページ目から開く）。

## テーマ

| テーマ | 大きさ | 見た目 |
|---|---|---|
| Boadilla（既定） | 1280 × 720（16:9） | Beamer の Boadilla（上端に節とページの丸の帯、丸い箇条書きの印） |
| Madrid | 960 × 720（4:3） | Beamer の Madrid |

テーマは `<html theme="…">` で選びます。URL に `?theme=Madrid` を付けると、開くときに変えられます。
画面の大きさ、書体、括弧と句読点の空きはテーマの CSS が決め、画面への合わせ方・ページ一覧の縮小・印刷の用紙はその大きさに従います。
タグの代わりに class で書く `ul.pts`（箇条書き）と `.blk`（block）は、Boadilla でだけ効きます。原稿ではタグ（`list`・`block`）を使います。

## 日本語と英語

一つの原稿に日本語と英語を並べて書き、発表のときにどちらか一方を出せます。
英語は外で作り（手で書くか翻訳にかけるか）、原稿に書き込みます。エンジンが行うのは、言語の切り替えと、その言語での組みだけです。

書き方は三通りあります。

- 文の中：`<p><ja>日本語の文</ja><en>English sentence</en></p>`。段落ごとに一組にするのを基本にします。
- 要素ごと：`lang="ja"` の要素のすぐ後に `lang="en"` の要素を置くと、それがその英語になります（`<div>`、SVG の `<g>`・`<tspan>` など）。
- 属性：`title`・`cite`・`label`・`sec`・`aff`・`short` は、`title-en="…"` のように `-en` を付けた属性に英語を書きます。

英語の無い日本語は、どちらの言語でも日本語のまま出ます。英語の一つも無い原稿は、これまでどおりの日本語だけの原稿です。

切り替えは、プレゼンのモード（下の「モード」）の道具「日本語 ⇄ English」かキー L で行います。URL に `?lang=en` を付けるとその言語で開き、選んだほうはブラウザが覚えます。既定は `<html lang="…">` の言語です。
英語は日本語より長くなりやすいので、収まらないページはその言語のときだけ文字を少しずつ縮めて収めます（85% まで）。それでもはみ出すページは、下の組版の検査が報告します。

英語ごとに、どの日本語から作ったかを記録しておくと、日本語を直したときに古くなった英語がわかります。

```
make lang SRC=talk/talk.html          # 英語の無い日本語・対の欠け・古い英語・記録の無い英語を行番号つきで出す
make lang-stamp SRC=talk/talk.html    # 記録の無い英語に、元の日本語のハッシュを書く（`<en ja="…">`。属性の英語は `title-en-ja="…"` のように、属性名に `-en-ja` を付けて書く）
python3 tools/lang_pairs.py stamp --force talk/talk.html   # 英語を全部作り直したとき、全ての記録を書き直す
```

編集モード（⌘E。下の「モード」）で英語を出すと、古い英語（記録と今の日本語が違うもの）と英語の無い日本語に印が付き、その数が画面の下に出ます。
印を見て英語を直したら、外で直した英語を書き込み、`stamp --force` で記録を新しくします。

## 配布用ファイルを作る

原稿は engine/ の JS・CSS・書体を読むので、そのままでは一つのファイルとして渡せません。

```
make pack SRC=talk/talk.html               # talk/talk.dist.html ができる（git で追跡しない）
make pack SRC=talk/talk.html THEME=Madrid  # テーマを変えて作る
```

`.dist.html` はそれ一つで、ネットにつながずに file:// で開けます。中身はエンジンの JS・CSS、組み終えた数式、画像、書体です。
中に入れるのは、原稿のフォルダと engine/ のフォルダの中のファイルだけです。その外のファイルを使うときは `ALLOW=フォルダ`（複数は空白で区切る）で許します。
画像・動画・音声・script・CSS は中に入ります（大きな動画は大きなファイルになります）。リンク先・iframe・object のファイルは入らないので `make pack` が警告し、配るときはそれらを `.dist.html` の隣に置きます。
Boadilla の書体は `fonts/` の書体ファイルから原稿で使う字だけを切り出して入れ、見本で約 0.7 MB です。
Madrid の IPA Pゴシックは許諾の条件により絞らずに入れるので、約 8.8 MB になります。
`make pack` は `make deps fonts` を先に行うので、`make engine-fonts`（原稿をそのまま開くときの書体）は要りません。
同じ原稿からは何度作っても同じバイト列になります。

直すのは原稿です。`.dist.html` は手で直さず、作り直します。`make clean SRC=talk/talk.html` で消せます。

## 組版の検査

```
make check-pack SRC=talk/talk.html                                # 配布用ファイルを作り、それを検査する
make check-pack SRC=talk/talk.html THEME=Madrid ENGINES=chromium,webkit,safari
make browsers && node tools/check_layout.mjs talk/talk.html       # 原稿をそのまま検査する
```

検査するのは次の三つの見え方です。

- 画面：各ページで段階表示をすべて出した状態と、切り替える図の各図
- 印刷：段階ごとの印刷の各紙。紙の大きさが画面と同じか、段階が n 組のページから 0, 1, …, n 組を出した n + 1 枚ができるか
- PDF：Chromium では実際に PDF を作り、ページ数と用紙の大きさを確かめる

報告する問題は次のとおりです。いずれかがあれば終了コード 1 で終わります。

- 画面（幅 × 高さ）の外に出た文字・block
- 本文の領域の外に出た文字・block。本文の領域は、Madrid ではページの枠の内側、Boadilla ではページの余白の内側です。
  Beamer の block のように負の余白でわざと張り出す block は、その分だけ許します。見出し・上端の帯・ページ番号・下の帯と、絶対配置の部品は、画面の外に出たときだけ報告します
- 自分の段落より幅の広い文字（切れない長い語や数式）
- 枠に切られて見えない中身（下の帯で「…」に省略された著者名なども含む）
- 行の切れ方の違い（ブラウザの間、および同じブラウザの画面と印刷の間）

英語を含む原稿は、日本語と英語のそれぞれで同じ検査を行います。文字を縮めて収めたページは情報として出し、縮めてもはみ出すページは問題として報告します。

印刷と PDF は、切り替える図を 1 枚目の図で組みます。ほかの図は画面でだけ検査します。
`safari`（その Mac のシステムの WebKit）は画面だけを検査します。

## キー

- 進む：→ / Space / Enter / PageDown / クリック。戻る：← / PageUp / 画面の左 1/4 のクリック。Home / End で最初と最後のページ。
  タッチの画面では、画面に出る ◀ ▶ のボタンでも進み・戻ります。
- 段階表示は既定でオンです。S で「全部出す」（ページだけを送る）と切り替え、選んだほうはブラウザが覚えます。
- ボタン・入力欄・リンク・動画・音声・details などのクリックでは、ページを送りません。
- ブラウザが覚える設定（段階表示・言語・日本語の太さ）は、同じ場所から開く全ての原稿で共通です。file:// で開く原稿は、多くのブラウザで全て同じ場所として扱われます。

## モード

道具はページの左の隙間に、縦一列のアイコンで並びます（名前とキーはアイコンに指を置くと出ます）。
いちばん下のつまみを押すと上へ開きます。上には今のモードの道具、下には三つのモード（編集・プレゼン・出力）とつまみが並び、モードは三つから一つを選びます。
モードのアイコンを押すとそのモードに移り、道具もそちらに替わります。既定はプレゼンです。
ページは欄の分だけ左に隙間を空けて置かれます。全画面表示では隙間を空けずに画面いっぱいに置き、欄はマウスを寄せたときに重ねて出します。
出力では、並べた版面の左の隙間に欄が出ます。モードのキーをもう一度押すとプレゼンに戻ります（Windows では ⌘ の代わりに Ctrl）。

- 編集 ⌘E：文をクリックして直し、Enter で原稿へ書き戻します。Chrome 拡張 page-edit（[page-edit/README.md](../page-edit/README.md)）が要り、無いときは見出しが灰色になります。
  道具はページ一覧 ⌘B と日本語の太さです。
- プレゼン：全画面 ⌘F、ポインター ⌘K、段階表示 S、ページ一覧 ⌘B、選択 ⌘I、キー無効 ⌘U、日本語の太さ（「A」を押すと「+」・値・「−」が出て、値を押すとテーマの値に戻る）。
  選択 ⌘I は文字を選べる状態で、クリックではページを送らず ← → だけで送ります。
  キー無効 ⌘U はキーでもクリックでもページを送らない状態で、その間だけ右上に印が出ます。選択とキー無効はどちらか一方だけになります。
- 出力 ⌘P：印刷の版面を画面に並べ、形式（段階ごと・全段階・HTML）を選んで「出力」を押します。
  PDF（段階ごとに 1 枚／全段階を 1 枚に）は印刷の画面で「PDF に保存」を選びます。
  HTML（1 ファイル）は、page-edit があるとき原稿の隣に `原稿.dist.html` を書きます。
  書体を間引かず KaTeX を丸ごと入れるので `make pack` より大きく（見本で約 13 MB）、make pack の検査もしません。
  page-edit が無いときや配る版は `make pack` を使います。

## ファイル

- `kamishibai.js`：エンジンの本体。最初の説明に書き方の一覧がある

- `fonts/`：書体の CSS。Madrid の `cm-sans.css`・`ipa-pgothic.css` は同梱、Boadilla の `kamishibai-fonts.css` は `make engine-fonts` で作る
